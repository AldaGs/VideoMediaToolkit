# VMT - Video & Media Toolkit

A professional, high-performance media toolkit for video transcoding, audio extraction, and image conversion. Built with Electron, React, and FFmpeg.

## Features
- **High-Quality Transcoding**: Support for ProRes, HEVC, H.264, VP9, and more.
- **Alpha Support**: Preserve transparency in modern codecs.
- **GIF Generation**: High-quality GIF conversion using Gifski.
- **Audio Tools**: Extract and convert audio with advanced controls.
- **Security**: Built-in protection against inspection and tampering.

## Development

### Install
```bash
$ npm install
```

### Run
```bash
$ npm run dev
```

## Build

### For Windows
```bash
$ npm run build:win
```

### For macOS
```bash
$ npm run build:mac
```
